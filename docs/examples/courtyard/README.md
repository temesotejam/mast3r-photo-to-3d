# ETH3D courtyard

These four overlapping photographs are views 0286–0289 of the ETH3D high-resolution multi-view courtyard dataset by Thomas Schöps et al., “A Multi-View Stereo Benchmark with High-Resolution Images and Multi-Camera Videos”, CVPR 2017. This repository uses the 800-pixel JPEG copies published with visloc-rs and produces a colored point cloud with MASt3R. The photos and derived courtyard example are shared under CC BY-NC-SA 4.0.
